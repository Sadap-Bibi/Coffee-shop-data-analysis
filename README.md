# Coffee Shop Sales Analysis in Excel

Hey there!  
I recently started learning **Excel** and decided to put my skills into action by analyzing coffee shop sales data. ☕📈

In this project, I:

- **Cleaned and transformed** the dataset
- **Added key insights** to highlight sales and customer trends
- **Built a dynamic Excel dashboard** that updates automatically based on the selected month or week—all with just a click!

## What I Learned

- Data cleaning and transformation
- Creating Pivot Tables and Pivot Charts to uncover insights
- Automating reports using dynamic filtering
- Enhancing decision-making with easy-to-read, data-driven visuals

## Project Highlights

- **Interactive Dashboard:** View sales performance, customer trends, and top-selling products for any month or week.
- **Dynamic Filtering:** Instantly filter and update reports without manually changing the data.
- **Professional Visualization:** Clean, simple charts that make key insights pop.
